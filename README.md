# empiria-tour

Tour-booking app for the Empiria platform. Uses the **empiria-shop** design
system, with **Supabase Auth** instead of Auth0.

The Next.js project lives in the nested [`empiria-tour/`](empiria-tour/)
directory (matching the layout of the sibling Empiria repos). See
[`empiria-tour/README.md`](empiria-tour/README.md) to get started.
